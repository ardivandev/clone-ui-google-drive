# Clone Google Drive Project

Website ini merupakan replika tampilan antarmuka (UI clone) dari platform penyimpanan cloud Google Drive, dibangun menggunakan HTML dan CSS murni tanpa framework. Proyek ini berfokus pada peniruan tata letak dashboard, navigasi sidebar, dan komponen visual yang menyerupai Google Drive asli.

## Teknologi

1. HTML5
2. CSS3

## Assets

1. Bootstrap Icons
2. Wikimedia Commons
3. Lobehub
4. Magnific
